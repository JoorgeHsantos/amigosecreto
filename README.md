# Amigo Secreto

Projeto simples para organizar e sortear nomes em um **Amigo Secreto**.

## Como funciona
1. Digite o nome dos participantes no campo de texto.
2. Clique em **Adicionar** para incluir cada nome na lista.
3. Após adicionar todos, clique em **Sortear Amigo** para sortear automaticamente.

## Tecnologias usadas
- **HTML** → estrutura da página
- **CSS** → estilo e layout
- **JavaScript (app.js)** → lógica do sorteio

## Estrutura do projeto
- `index.html` → página principal
- `style.css` → estilos do site
- `app.js` → lógica do sorteio
- `amigo-secreto.png` → logo utilizada no projeto
